# Factora — usine à vidéos éducatives

- `engine/` : moteur (voix Kokoro, rendu vectoriel Cairo, sous-titres, musique générée, export MP4).
- `episodes/NNN-sujet/` : script, scènes dessinées, métadonnées YouTube de chaque épisode.
- `topics.md` : file d'attente des sujets. `published.json` : historique des publications.
- `CLAUDE.md` : procédure suivie chaque jour par la session automatique.
